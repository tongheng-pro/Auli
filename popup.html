How to edit EMR data
  1. Click Export CSV and open the file in Excel or Google Sheets.
  2. Edit it. One row = one value. Rows with the same group, page and section form one list.
    • Change a value: edit the cell.
    • Add a value: add a row and copy the group, page and section from a row of that list.
    • Add a group: add rows with a new group name.
    • Remove a value: delete its row. Duplicate names in the same list (ignoring capitals) are skipped.
  3. Save as CSV UTF-8 (Excel: File › Save As › "CSV UTF-8"), so Khmer text is kept. Files that use ; instead of , also work.
  4. Click Import file…, choose it and confirm. It replaces all current EMR data, so export first if you want a backup. If something is wrong, you'll see the row number and nothing changes.
Columns
groupRequired. Group name. Use the same name as the list in the hospital system (e.g. Birth Control Type) so "Sync all" can match it.
codeCode (optional; e.g. OBVA-S000099). If empty, the English name is used.
englishRequired. English name of the value (e.g. Combined Oral Contraceptive (COC)).
khmerKhmer name (optional; e.g. ថ្នាំគ្រាប់ស៊ីអូស៊ី). Created instead of the English name when "Khmer name only" is chosen.
descriptionLonger English description (optional).
page, sectionGroups lists in the group picker (optional; "Custom" if empty). The same group name under a different page or section becomes a separate list.

Team Google Sheet: in Google Sheets, File › Import › upload the exported CSV. Click Share › General access › Anyone with the link (Viewer), or use File › Share › Publish to web. Paste the sheet link above and turn on Keep in sync. Your team edits the sheet; while Auli is open it picks up changes within 30 seconds. Use the tab the link points to (the #gid= part). If a row has a problem, the current data is kept until it is fixed. Importing a file or resetting turns Keep in sync off.
